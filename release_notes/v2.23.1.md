# WhisperDoc Technical Release Notes - v2.23.1
**Version Range: v2.22.2 to v2.23.1**

This release introduces a **multi-engine ASR abstraction layer**, enabling pluggable speech-to-text backends behind a unified interface. It also includes a complete transport race-condition sweep, model lifecycle hardening, and a full test suite realignment. The backend is now architecturally prepared for Groq, Parakeet, or any future ASR provider with zero protocol changes.

## Multi-Engine Architecture

### BaseEngine Abstraction
- Introduced `BaseEngine`, an abstract contract defining `transcribe`, `warmup`, `is_loaded`, and `unload` — all engine implementations conform to this interface, decoupling the WebSocket handler and HTTP API from any specific ASR backend.
- Added `TranscriptionResult` and `SegmentResult` dataclasses as the normalized output format, replacing raw model-specific return types.

### WhisperEngine
- Wrapped the existing `ModelManager` behind a `WhisperEngine` implementation of `BaseEngine`. Transcription hyperparameters (beam size, no-speech threshold, log probability, condition-on-previous) are baked at construction time via environment variables — consistent config without per-call overhead.
- Lazy CTranslate2 generators are materialized inside `asyncio.to_thread` to prevent cross-thread undefined behaviour from the C++ context.

### ParakeetEngine
- Added `ParakeetEngine` for NVIDIA NeMo `parakeet-tdt-0.6b-v2` with thread-safe model loading, timestamp extraction from NeMo hypothesis objects, and graceful fallback when segment timestamps are unavailable.
- Model selection rationale documented in `.env.template`: v2 outperforms v3 on real-world benchmarks (avg WER 6.05 vs 6.32), and 0.6b generalises better than 1.1b on conversational audio.

### Engine Factory
- `create_engine()` dispatches on the `ASR_ENGINE` environment variable (`whisper`, `parakeet`) with deferred imports per engine to prevent cross-image dependency creep. Unknown engine names fail fast with a clear error.

## Model Lifecycle Hardening

### Cache-First Loading
- `ModelManager.load_model()` now attempts `local_files_only=True` first to skip the HuggingFace API revision check when the model is already cached at `/app/model-cache`. Falls back to network download only on genuine cache miss — eliminates two HTTP requests on every container start and reconnect.

### Warmup Guard
- The post-handshake warmup trigger in `ConnectionManager` is now gated behind `if not self.engine.is_loaded()`, skipping the background thread spawn entirely for reconnecting clients whose model is still resident in VRAM.

### Coroutine Safety
- `asyncio.create_task` calls in `ModelManager.__init__` and `ConnectionManager.__init__` are guarded with try/RuntimeError/close to properly dispose of the coroutine in sync test contexts, eliminating 12 "coroutine never awaited" RuntimeWarnings.

## Transport Race Condition Fixes (v2.22.3)

### Backend Eviction
- Replaced the flawed Slowloris throughput check with a precise slot-hogging detector: tracks `last_audio_received` and evicts authenticated connections that never send audio within `NO_AUDIO_GRACE_SECONDS` or go silent longer than `IDLE_TIMEOUT_SECONDS`, preventing false-positives on push-to-talk clips.
- Changed eviction close code from 4000 to 4001 to give clients a machine-readable signal distinct from generic inactivity timeout.

### Client Transport (Flutter)
- Fixed stale-audio flush ordering: moved `_audioBuffer.flush()` out of the handshake state listener and inline into the `authenticated` branch of `_handleRawMessage`, gated behind `!_pendingConfigChange`, so buffered audio is never written to a session with stale URI or credentials.
- Fixed mid-handshake config-change drop: narrowed `onReconnectNeeded` guard to `connected` only, preserving the signal during `connecting` state and consuming it with an immediate reconnect that bypasses the 5-second backoff timer.

## Test Suite Realignment

### New Test Modules
- `test_engine_contract.py`: Parametrized fixtures verifying all engine implementations against the `BaseEngine` contract — return types, segment integrity, warmup idempotency.
- `test_engine_factory.py`: Factory dispatch tests for whisper, parakeet, and unknown engine error paths.
- `test_whisper_engine.py`: Generator materialization, segment joining/stripping, lifecycle delegation.
- `test_parakeet_engine.py`: NeMo transcript mapping, timestamp extraction, fallback behaviour.

### Regression Fixes (15 Tests)
- Added `conftest.py` with `.env` auto-loader and `ALLOWED_HOSTS=testserver,localhost` for `TrustedHostMiddleware` compatibility with Starlette's `TestClient`.
- Rewrote privacy tests to mock `BaseEngine.transcribe` returning `TranscriptionResult` instead of the removed `ModelManager.get_model()` pattern.
- Fixed protocol enforcement tests to consume the error JSON message before asserting `WebSocketDisconnect`.
- Updated WebSocket handshake tests to send `MIN_CLIENT_VERSION`-compatible version strings.
- Corrected health check assertion from `"healthy"` to `"online"` and audio path from `assets/jfk.flac` to `../assets/jfk.flac`.
